# Atlas onboarding example

This directory is a complete synthetic onboarding bundle. From the repository
root, run:

```bash
covale-onboard-atlas examples/atlas_onboarding
```

The command validates and canonicalizes the two labels, copies the bundle
under `covale/atlas_registry/atlases/atlas_onboarding/`, and adds the atlas
and its stable region IDs to `covale/atlas_registry/registry.json`.

The volume is synthetic and is not suitable for scientific use.
